# ATS v0.4.1 — Manutentore e metadati

**Data:** 11 novembre 2026 · **Repository:** [EnrCol/ats-ha](https://github.com/EnrCol/ats-ha) · **Tipo:** release stabile di manutenzione

## Modifiche rispetto alla v0.4.0

- **Made by the community:** il campo `codeowners` del manifest ora indica **[@EnrCol](https://github.com/EnrCol)**, manutentore del fork e destinatario delle segnalazioni.
- **Attribuzione originale preservata:** il progetto deriva da [Manu-Nat/ats-ha](https://github.com/Manu-Nat/ats-ha); README italiano/inglese e file `LICENSE` mantengono i crediti e il copyright originale a Manu-Nat.
- **Documentazione e installazione:** README IT/EN, link al tag stabile, checklist e note di rilascio allineati alla v0.4.1. Il collegamento a documentazione e issue tracker rimane sul fork `EnrCol/ats-ha`.
- **Risorsa Lovelace:** il parametro di versione del modulo JavaScript ATS passa a `?v=0.4.1` per il normale aggiornamento della cache. La card e la relativa logica non cambiano.
- **Test e pubblicazione:** controlli aggiornati per verificare versione, manutentore, link e descrizioni. Il tag stabile viene pubblicato solo dopo la CI verde di `main`.

## Compatibilità

**Nessuna modifica funzionale** a login, sensori, `ats_metric`, `unique_id`, fatture, download PDF, visualizzatore PDF.js, database Recorder o algoritmi di calcolo.

Per aggiornare da v0.4.0 installa v0.4.1 tramite Marketplace/HACS e riavvia Home Assistant. **Non eliminare e ricreare l'integrazione**: così vengono mantenuti la config entry e gli identificativi registrati. La libreria JavaScript aggiorna il proprio URL in Lovelace; se necessario ricarica completamente la pagina o riapri la Companion App.

**Nessuna credenziale, dato personale, bolletta o backup è incluso nel repository.**

Per tutte le funzionalità, i limiti e le informazioni sulla privacy, consulta il [README italiano](https://github.com/EnrCol/ats-ha/blob/v0.4.1/README.md), il [README inglese](https://github.com/EnrCol/ats-ha/blob/v0.4.1/README.en.md) e le [note della v0.4.0](https://github.com/EnrCol/ats-ha/blob/v0.4.1/docs/releases/v0.4.0.md).
